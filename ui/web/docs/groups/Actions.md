# Actions components

Generated by `bun run ui:docs`. Back to the [index](../../COMPONENTS.md).

- [Button](../components/Button.md): A text button: Default, Primary for the main action, Danger, or Danger primary for
  a destructive confirm.
- [IconButton](../components/IconButton.md): A borderless icon button, optionally with text after the icon; `label` is
  its name and tooltip.
- [Segmented](../components/Segmented.md): A row of mutually exclusive choices (a toggle group), like Light / Dark /
  System. Arrow keys move.
- [Icon](../components/Icon.md): A stroke icon on a 24px grid in the current text color. The preview lists every icon
  name.
- [SplitButton](../components/SplitButton.md): A main action joined to a menu of related actions, like Commit with
  Commit and Push.
- [LayoutIcon](../components/LayoutIcon.md): The drawn layout glyphs: a window with its left or right sidebar, and the
  commit box layouts.
- [ToggleButton](../components/ToggleButton.md): A button that stays on or off, such as Collapse unchanged in the diff
  or the merge editor's options.
- [Chip](../components/Chip.md): A small rounded button with a word or two: a filter summary or a value to pick.
- [Link](../components/Link.md): A button that looks like a link, for a small action in text or under a list.
- [Tile](../components/Tile.md): A big start action: its icon on a rounded tile and its name under it.
