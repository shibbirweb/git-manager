# Forms components

Generated by `bun run ui:docs`. Back to the [index](../../COMPONENTS.md).

- [Input](../components/Input.md): A single-line text field. `invalid` draws a red border; Field shows the message under
  it.
- [TextArea](../components/TextArea.md): A multi-line text field, like the commit message box.
- [Select](../components/Select.md): A native drop-down list, styled like Input.
- [Checkbox](../components/Checkbox.md): A native checkbox with its label; clicking the text toggles it too.
- [RadioGroup](../components/RadioGroup.md): Native radio buttons for one choice among a few, each with an optional
  description.
- [Switch](../components/Switch.md): An on/off switch for a setting that applies at once.
- [Slider](../components/Slider.md): A range slider with its value on the right, like Settings' font size.
- [Field](../components/Field.md): A labelled form field: the label, the control, then a hint or an error under it.
- [SettingRow](../components/SettingRow.md): A Settings row: title and hint on the left, the control on the right, or
  under them when stacked.
- [SearchField](../components/SearchField.md): A filter box with a magnifier and a clear button, like Settings' search.
  Esc clears, then blurs.
- [Fieldset](../components/Fieldset.md): A group of options under a legend, like Pull's choices of how to integrate
  changes.
- [ShortcutRecorder](../components/ShortcutRecorder.md): A command's keys that can be changed: click, press the new
  keys, Esc cancels.
- [ChoiceList](../components/ChoiceList.md): A few answers to pick from, each a card with a label and a line of
  description.
- [RenameField](../components/RenameField.md): A name edited in place: a small accent-bordered field; Enter keeps,
  Escape cancels, red when taken.
- [OptionList](../components/OptionList.md): A bordered list to pick one option from, in groups, like Settings' color
  themes.
