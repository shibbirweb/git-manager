# Feedback components

Generated by `bun run ui:docs`. Back to the [index](../../COMPONENTS.md).

- [Spinner](../components/Spinner.md): A small spinning ring for work in progress.
- [Badge](../components/Badge.md): A count in a small pill, like the changes count on the activity bar; "99+" above
  `max`.
- [Tag](../components/Tag.md): A small label beside a name, like "primary" or "folder" in the AI panel.
- [Kbd](../components/Kbd.md): A keyboard shortcut drawn as a key cap.
- [ProgressBar](../components/ProgressBar.md): A thin bar for a share of a whole, like each process's memory in the
  status bar details.
- [Notice](../components/Notice.md): A tinted banner with an icon, a message and an optional action on the right.
- [EmptyState](../components/EmptyState.md): The centered message of an empty panel or tab, with an optional icon, hint
  and action.
- [Notification](../components/Notification.md): One notification: the kind's icon, a bold title, where it came from,
  the detail and an action link.
- [StatusLetter](../components/StatusLetter.md): A changed file's status letter in its color: A, M, D, R, U, C or T.
- [FileIcon](../components/FileIcon.md): A file's type icon, resolved by the app from the chosen icon set and passed in
  as `view`.
- [RefLabel](../components/RefLabel.md): A ref chip in the log: HEAD, local and remote branches, tags, bisect marks and
  a +N chip.
- [StatusIcon](../components/StatusIcon.md): An agent's or task's state: spinner, question mark, check, square or ring.
- [ThemeSwatch](../components/ThemeSwatch.md): A color theme's preview chip: code on its background and bars of its main
  colors.
- [StatusDot](../components/StatusDot.md): A small round dot that tells a state: a command's result, a server on or off,
  a run going on.
- [Avatar](../components/Avatar.md): Initials in a round accent circle (an account) or a rounded tile in a palette color
  (a project).
- [Pill](../components/Pill.md): A rounded word that tells a state: unsaved, modified, merging, write.
- [Mark](../components/Mark.md): A tiny box with one to three letters that names a tool, such as an AI agent.
- [Meter](../components/Meter.md): How much of something is used: a label and value over a bar.
- [ZoomBadge](../components/ZoomBadge.md): A floating badge at the top of the window that shows a value for a moment,
  such as the zoom level.
- [SymbolBadge](../components/SymbolBadge.md): A one-letter badge for a code symbol's kind, in the syntax color of its
  group.
- [Logo](../components/Logo.md): The app's logo: the merge mark on an accent tile.
- [BulletList](../components/BulletList.md): A short bulleted list of facts, such as the settings changed from their
  defaults.
- [CornerCard](../components/CornerCard.md): A small card in a view's bottom right corner with a message and a button,
  like The agent ended.
- [DragGhost](../components/DragGhost.md): The label that follows the pointer while files are dragged.
