# Navigation components

Generated by `bun run ui:docs`. Back to the [index](../../COMPONENTS.md).

- [TabStrip](../components/TabStrip.md): The editor's tab strip: icon, name, hint and a close button; a dot for unsaved
  edits, italic previews.
- [Tabs](../components/Tabs.md): Panel tabs in small capitals with an accent underline, like Terminal / Run / Git
  Console.
- [Tree](../components/Tree.md): A file-tree list: folders open and close, rows indent by depth, and only rows in view
  are drawn.
- [VirtualList](../components/VirtualList.md): A long list that draws only the rows in view, for thousands of rows of
  one fixed height.
- [Collapsible](../components/Collapsible.md): A section whose header opens and closes it: chevron, bold title, count
  and hover actions.
- [ListRow](../components/ListRow.md): A row of a pick or command list: a label and a dim description; the highlighted
  row is accent-filled.
- [PickList](../components/PickList.md): A filterable list to pick one item: words filter, arrows move, Enter picks, Esc
  cancels.
- [Breadcrumbs](../components/Breadcrumbs.md): A path as crumbs separated by chevrons, like the Navigation Bar; the file
  is bold.
- [List](../components/List.md): The keyboard and selection around Rows: a listbox, a tree or a plain list, optionally
  virtual.
- [FileRow](../components/FileRow.md): A changed file in a list: status letter, type icon, name, dim folder, tag and
  hover actions.
- [SidebarRow](../components/SidebarRow.md): A sidebar row for branches, tags, stashes and worktrees, or a small-caps
  group heading.
- [SideNav](../components/SideNav.md): A vertical list of sections with the open one marked, like the Settings sections.
- [EditorTab](../components/EditorTab.md): One tab of a TabStrip: icon, name, hint and close button (a dot while
  unsaved).
- [TreeRow](../components/TreeRow.md): One row of a Tree: chevron, icon, name or rename field, decoration and detail.
- [DataTable](../components/DataTable.md): A table of many rows with a header, like the log: named column widths, a lead
  column, selection.
- [ReorderList](../components/ReorderList.md): Rows the user orders by dragging their grip, like Interactive Rebase's
  commits.
- [ResourceLink](../components/ResourceLink.md): A large row that opens something to read or do: icon, title and a line
  of description.
- [SessionTabs](../components/SessionTabs.md): A strip of running sessions: state icon in its color, name and close; the
  selected one underlined.
- [Table](../components/Table.md): A short table in a bordered box: a sticky header and 28 px rows that can be selected.
- [PopupRow](../components/PopupRow.md): A row of a picker popup: an action, or an item with an icon, a name, a hint and
  a chevron.
